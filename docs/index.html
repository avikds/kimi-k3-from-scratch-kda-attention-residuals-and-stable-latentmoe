Kimi K3 from Scratch: KDA, Attention Residuals, and Stable LatentMoE

How it was built

Part 1: KDA Projections and Decay

Build KDA's input pathway: the short causal conv, Swish/L2Norm q-k-v projections, the write-strength and decay-logit gates, and Kimi K3's lower-bounded scaled-sigmoid decay.

Part 2: KDA Recurrence and Chunkwise Form

Implement the delta-rule state recurrence, then reproduce it exactly with the chunkwise-parallel form (cumulative decay, triangular-solve pseudo-values, inter/intra-chunk outputs) and the full-rank output gate.

Part 3: Gated MLA with NoPE

Compress KV into a latent, reconstruct per-head keys and values, run causal attention with no positional encoding, gate the output, and lay out the 3:1 hybrid KDA/MLA layer schedule.

Part 4: Attention Residuals

Replace the residual stream with attention over depth: pseudo-query weighting over RMS-normalized layer outputs, the full form, and the O(N)-memory block form with running partial sums.

Part 5: Stable LatentMoE

Build SiTU-GLU's softly capped experts, the aux-loss-free sigmoid router, sparse latent dispatch, and the full layer with RMSNorm before the up-projection.

Part 6: Quantile Balancing

Balance expert load without auxiliary losses: Top-(k+1) cutoffs, the order-statistic bias update that hits exact target loads, and the histogram estimator that makes it distributed-friendly.

Part 7: Per-Head Muon

Implement Newton-Schulz orthogonalization and Kimi K3's per-head variant, showing how full-matrix orthogonalization starves small-scale heads.

Part 8: Mini K3 Assembly

Assemble the hybrid stack, Attention Residuals, and Stable LatentMoE into a miniature Kimi K3 and verify causality end to end.
